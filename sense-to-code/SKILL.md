# Sense to Code

## When

CONTROL-01 reports a sensation, a Sense Lab event, or asks to map sense → artifact. Never invent the felt quality.

## Inputs

- Live lab: https://quiet-willow-raven-dawn.grok.me
- CONTROL_SECTOR.md, SCOPE.md, BASELINE_v0.md, PIPELINE.md
- Optional: Pulse GRO-5, Naixus site-walk

## Sequence

1. Name theatre (this chat / Build / Bot / body).
2. Tag source: self, world, unknown.
3. Fill the cell schema. Leave felt_true null until CONTROL-01 speaks.
4. If the cell cannot describe work or stop, say so. Do not decorate.
5. Artifact only when asked: Pulse note, Roof Ops brief, or this-chat dictionary line.
6. Stop if he says stop.

## Validate

- Mapping matches BASELINE_v0 unless he accepted a change.
- No Neuralink, no extra Bot, no silent repo push.
- Mic NO MIC ≠ a pitch observation.

## Return

One cell + one next action, or a named hole.
